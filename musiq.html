Musiq—

[ Project ]

A fast, minimal music player for people who live in the terminal.

Musiq is a lightweight, keyboard-first music player written in Rust, with a terminal UI as the primary interface and an optional minimal GTK window for anyone who wants a mouse-driven fallback. It was built to stay out of the way: low memory use, instant startup, gapless playback of a local library.

There's no account, no streaming layer, and no telemetry — it plays files that are already on disk. Code is at github.com/CEONEINDEDALUS/musiq.

How it works

  • 01Keyboard-driven TUI

    Every action — browsing, queueing, seeking — has a keyboard shortcut, so a full session can run without touching a mouse.

  • 02Optional GTK window

    A minimal GTK front-end wraps the same playback engine for anyone who prefers a window over a terminal.

  • 03Local library indexing

    Tracks are indexed from tags on disk. No cloud service, no external database, no dependency on an internet connection to browse or play.
