Synthgrid—

[ Project ]

Describe the transformation. Get the spreadsheet.

Synthgrid edits CSV and XLSX files from a plain-English instruction — "merge these two columns", "flag rows where revenue dropped", "convert this to weekly totals" — instead of a formula or a macro. It uses Groq's inference for the language step, which keeps the round-trip fast enough to feel interactive rather than batch.

Every change is shown as a diff before it's applied, so nothing gets overwritten silently. Only the instruction text is sent to the Groq API; the underlying data stays local. Source and issue tracker: github.com/CEONEINDEDALUS/synthgrid.

How it works

  • 01Instruction to transform

    A natural-language request is compiled into a concrete pandas operation or formula, not run as an opaque black box.

  • 02Preview before apply

    Every transform shows a before/after diff of the affected rows and columns first, so a bad instruction is caught before it touches the file.

  • 03Local files, transparent network use

    Spreadsheet data is processed on disk. The only thing that leaves the machine is the instruction text sent to Groq.
