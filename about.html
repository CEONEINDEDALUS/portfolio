[ About ]

Security. Creativity. Passion.

I build systems, apps, and tools — and I test myself against them on the security side. Breaking my own work is part of finishing it.

I use Python, Rust, and Go. I build local-first AI tools and backend systems. Each project has a code repository, and I use each tool myself. If a tool is not good enough for my own work, it is not finished.

I want what I build to be useful first, but I care just as much that it feels like something — not just software, but a small piece of craft.
