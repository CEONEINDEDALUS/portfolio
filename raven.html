Raven

Local System Assistant

  • Python
  • Linux

A system assistant that lives in your terminal, not in the cloud.

Raven automates the routine parts of Linux system administration — process monitoring, log triage, disk cleanup, service restarts — from a plain-language command. It only executes actions from a pre-approved, auditable command set, and explains what a command will do before it runs anything that changes state.

This is the plain-language-risk principle from how I work generally: no jargon, no surprise side effects. Full source, including the command whitelist, is at github.com/CEONEINDEDALUS/raven.

How it works

01

Explain before execute

Any action that changes system state is described in plain language first and requires confirmation — there is no silent destructive path.

02

Log parsing and summarization

Raven can scan service logs and return a short summary of what actually needs attention, instead of a raw tail.

03

Reusable routines

Common sequences of actions can be saved as named routines and re-run later, so a fix written once doesn't need to be re-typed.
