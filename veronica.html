Veronica—

[ Project ]

Search your files without sending them anywhere.

Veronica indexes local documents — PDFs, Markdown, plain text, and code — and lets you search them by describing what you're looking for, instead of guessing the right keyword. The whole pipeline runs on your machine through a local Ollama model, so files never leave the folder they're already in.

It was built for a simple reason: most document search tools ask you to trust a third party with your archive. Veronica doesn't need that trust, because there's nothing to send. The repository is public at github.com/CEONEINDEDALUS/veronica if you want to read the indexing code before pointing it at anything sensitive.

How it works

  • 01Local indexing

    Veronica walks a directory, extracts text from each file, chunks it, and generates embeddings through a locally running Ollama model. No file content is ever transmitted.

  • 02Plain-language search

    Type a question the way you'd ask a person. Results are ranked by relevance and returned with the source file and line reference, not just a filename.

  • 03Airgap-friendly

    A network-off flag guarantees the process makes no outbound connections at all, so it can run on a machine that has no internet access by policy.
